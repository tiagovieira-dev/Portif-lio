Leitura dos cases

O que muda de um projeto para o outro

Institucional e sistema não pedem a mesma coisa. O recorte abaixo é o critério que aparece nos três trabalhos.

Vitrine

Site que explica o negócio

TRC e Madelog: hierarquia, contato e credibilidade. Sem dashboard onde não há login.

Operação

Sistema quando há cadastro

MadeiraGest: CRUD, API e banco. Entra backend só quando o dado precisa viver fora da página.

Stack

Ferramenta no tamanho certo

React na interface que pede componente. Node e MySQL no fluxo que pede persistência.

Uso

Pronto para o dia a dia

Tela que abre no celular, dado que se consulta de novo amanhã, código que outro dev consegue ler.

Antes de começar o seu

O que eu peço para não chutar escopo

As mesmas perguntas que separam um site institucional de um CRUD — para a proposta nascer fechada.

1

Qual problema some se o sistema existir?

Captação, catálogo, controle interno. Se a resposta for vaga, o escopo infla. Se for concreta, o card do case já tem título.

2

Quem abre a tela todo dia?

Cliente final, comercial ou operação. Isso define se o foco é conversão ou cadastro — e se React e banco entram ou não.

3

O que já existe hoje?

Planilha, Instagram, site antigo ou nada. O MadeiraGest nasceu de rotina real; o institucional, de quem ainda não tinha vitrine à altura.
