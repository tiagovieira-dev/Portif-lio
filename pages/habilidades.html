Critério

Quando cada camada entra

A lista acima não é um cardápio para usar tudo de uma vez. A escolha segue o problema, o prazo e quem vai manter depois.

Interface

HTML, CSS e JS primeiro

Landing, institucional e painel começam leves. React, roteamento e charts entram quando a interface realmente precisa de estado e composição.

Servidor

API só com regra de negócio

Express, JWT e PostgreSQL quando há login, cadastro e persistência. Sem backend “de enfeite” em site estático.

Operação

Git, Docker e VPS no momento certo

Versionar desde o dia um. Container e servidor quando o deploy deixa de caber em um host simples.

Qualidade

Lint e estudo contínuo

ESLint/Prettier no fluxo. Cursos e certificações para preencher lacuna real — não para inflar o rodapé.
